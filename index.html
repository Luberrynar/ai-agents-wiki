What is an AI agent?

  • An AI agent is a program that works toward a goal, uses tools, and acts with some independence.
  • Usually a large language model (LLM) decides what to do next.
  • Experts do not agree on one exact definition.

Agent, workflow or chatbot?

Chatbot without tools

No tools, memory or reasoning, so it needs your input at every turn.

Workflow

The developer fixes the steps in code. Predictable and consistent for well-defined tasks.

Agent

The model chooses its own steps and tools. Better when the task needs flexibility.

Start with the simplest option that works. Agents often trade speed and cost for better results, and one model call with good examples is often enough.

The agent loop

  • An agent works in a cycle: plan, act with a tool, look at the result, then decide whether to continue.
  • Each step should use real results, such as tool output, to judge progress.
  • Limits keep it safe: a maximum number of rounds, and pauses for human feedback.
  • The ReAct style repeats Think, Act, Observe.

Tools, memory and planning

Tools

The model asks for a tool, the program runs it, and the result goes back to the model. Tools include web search, APIs and other agents.

Memory

Agents can store past interactions, so later answers can be more personal.

Planning

The agent breaks a big goal into smaller subtasks. Simple tasks may not need a plan.

  • A tool is described to the model by a name, a description and an input format.
  • The software layer that manages prompts, tools, memory and permissions is called an agent harness.

Risks, safeguards and summary

What can go wrong

  • Higher cost and mistakes that pile up
  • Endless loops when the agent cannot plan well
  • In one test, no agent finished most of its tasks
  • A coding agent deleted a production database

Safeguards

  • Test in sandboxes with guardrails
  • Keep activity logs
  • Allow humans to interrupt
  • Get human approval before high-impact actions

In short: an agent is a model that uses tools in a loop to reach a goal. Choose the simplest design that does the job.
