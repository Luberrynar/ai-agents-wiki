# Memory and planning
**Summary:** Planning lets an agent break a big goal into smaller tasks, and memory lets it keep information from earlier steps or past use.
**Key points:**
- Agent systems may include memory components and planning logic alongside tools and orchestration software. (Source: source-01)
- IBM says agents store past interactions in memory and plan future actions, which makes answers more personal. (Source: source-03)
- Given a goal and tools, an agent breaks the goal into tasks and subtasks (task decomposition); for simple tasks planning may not be needed. (Source: source-03)
- Feedback from humans or other agents lets an agent refine its answers, and it can store solutions to past obstacles to avoid repeating mistakes. (Source: source-03)
- Anthropic says current models can decide what information to retain as part of an LLM augmented with memory. (Source: source-02)
- Google lists planning (identifying steps and choosing the best action) and memory as typical agent features. (Source: source-04)
