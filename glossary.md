# Glossary
**Summary:** Short definitions of terms used across the wiki.
**Key points:**
- **LLM (large language model):** the AI model at the core of most modern agents. (Source: source-03)
- **Agentic system:** Anthropic's umbrella term for both workflows and agents. (Source: source-02)
- **Workflow:** an LLM-and-tools system that follows predefined code paths. (Source: source-02)
- **Agent:** a system where the LLM directs its own steps and tool use. (Source: source-02)
- **Augmented LLM:** an LLM enhanced with retrieval, tools and memory. (Source: source-02)
- **Tool use / function calling:** letting the model call functions defined by the developer or provider. (Source: source-05)
- **Agent-computer interface (ACI):** the tools and their documentation that an agent works through, which deserve as much care as a human interface. (Source: source-02)
- **ReAct:** a Think-Act-Observe approach where the agent reasons after each action. (Source: source-03)
- **ReWOO:** an approach where the agent plans up front before using tools. (Source: source-03)
- **Model Context Protocol (MCP):** a standard way for LLM agents to get context and call external tools, introduced by Anthropic in late 2024. (Source: source-01)
- **Agent harness:** the software layer around an LLM that lets it work as an agent. (Source: source-01)
- **Orchestration:** coordinating agent components or several agents. (Source: source-01)
- **Human-in-the-loop (HITL):** humans giving feedback or approval during an agent's work. (Source: source-03)
- **Agent washing:** relabelling existing products as agentic. (Source: source-01)
