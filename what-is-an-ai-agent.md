# What is an AI agent?
**Summary:** An AI agent is a program, usually powered by a large language model (LLM), that is given a goal and can use tools and take several steps on its own, instead of only answering one question.
**Key points:**
- An AI agent is an AI program that pursues goals, uses software or other tools, and acts with some level of autonomy. (Source: source-01)
- Common features are goal-directed behavior, use of external tools, the ability to change an outside environment, and doing multi-step tasks on its own; there is no universally agreed definition. (Source: source-01)
- The agent's control flow is frequently driven by an LLM, and agent systems may also include memory, planning logic, tool interfaces and orchestration software. (Source: source-01)
- IBM describes an agent as a system that autonomously performs tasks by designing workflows with available tools, with an LLM at its core, so agents are often called LLM agents. (Source: source-03)
- Google describes agents as software systems that use AI to pursue goals for users, showing reasoning, planning, memory and some autonomy to decide, learn and adapt. (Source: source-04)
- Google compares three things: agents have the highest autonomy and act proactively; assistants respond to user requests while the user decides; bots follow predefined rules with little or no learning. (Source: source-04)
- A common use is task automation, for example booking travel plans from a prompted request. (Source: source-01)
